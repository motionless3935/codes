use ominis_core::prelude::*;
use ominis_sim::prelude::*;
use ominis_aleph::avionics::*;

// Define continuous physical control system
#[derive(System)]
pub struct AttitudeControlSystem {
    pub target_attitude: Quaternion,
    pub pid_gains: GainVector3,
}

impl FlightLoop for AttitudeControlSystem {
    fn step(&mut self, ctx: &mut Context) -> ActuatorCommands {
        let imu = ctx.read_sensor::<TripleImu>();
        let error = self.target_attitude * imu.quaternion.inverse();
        
        // Computes 100% identically in Cloud GPU Sim and STM32H7 hard-realtime
        let torque = self.pid_gains.calculate(error.to_euler_angles());
        ActuatorCommands::from_torques(torque)
    }
}

Ominis Systems is a next-generation aerospace autonomy platform that eliminates custom infrastructure for physical AI. We combine a GPU-accelerated simulation platform (written in Rust and Python via JAX/XLA) with the open, modular Aleph flight computer, giving aerospace engineers a single codebase from cloud testing to real-world flight.

Unlike traditional CPU simulation tools (such as MATLAB/Simulink or Gazebo) which run serial loops, Ominis compiles entire vehicle dynamics, aerodynamic forces, and numerical ODE solvers into GPU tensor operations via JAX and XLA (Accelerated Linear Algebra). This allows tens of thousands of flight profiles to execute in parallel across GPU threads in a fraction of a second.

Ominis decouples vehicle control systems from physical I/O through an Entity Component System (ECS) architecture. In Software-in-the-Loop (SITL) mode, sensor interfaces bind to high-fidelity virtual noise models and GPU physics. In Hardware-in-the-Loop (HITL) mode, the exact same Rust traits bind to hardware DMA buffers and JST-GH telemetry buses on the STM32H757 and NVIDIA Jetson Orin.

Aleph uses a dual-board open architecture connected by a high-density Samtec ERF5-050 connector. The Carrier Board houses an NVIDIA Jetson Orin SOM (up to 100 TOPS AI compute) with M.2 NVMe, USB-C 10Gbps, and GigE with PoE. The Expansion Board features a dual-core STM32H757 (Cortex-M7/M4), triple redundant BMI270 IMUs, BMP581 barometer, BMM350 magnetometer, CAN buses, UART/GPS, PWM ESC outputs, and an integrated RP2040 debugger.
